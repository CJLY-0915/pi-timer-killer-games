# 摸鱼小游戏

工作面板里的十款小游戏，外加一台记录你今天摸了多久的打卡机。

扫雷、2048、纸牌接龙、俄罗斯方块、贪吃蛇、数独、24 点，一款关掉面板也自己在转的工位模拟器，再加一台局域网五子棋和一张 2-5 人的局域网炸金花牌桌。没有开屏动画，没有联网排行榜，没有「登录后可同步」——点开就玩，关掉就走，最高分会自己留着。

插件 ID：`icedly.moyu-games` · 需要 PI-Desktop `>= 0.15.0`。只申请一个权限（右侧面板视图）。单机玩法不发任何网络请求，也不读自己数据目录以外的文件；局域网五子棋与局域网炸金花只在你创建或加入房间时才在同一网段内直连。

## 安装

- **插件中心**：PI-Desktop → 插件 → 插件中心 → 摸鱼小游戏。
- **开发**：插件 → 加载开发插件 → 选本仓库根目录。改动 `views/` 会热重载；只有加宽权限才需要重新加载一次。
- 装好后，右侧工作面板的视图切换里会出现「摸鱼小游戏」。

## 十款游戏

- **游戏库首页** — 顶上是一台翻页时钟，读数是今天摸鱼的总分钟数；下面每行一张「打卡」战绩，写着各游戏的最高分或胜负。没开局的行标着「未开局」。上次玩到哪，首页会给你一个「接着摸」的入口。
- **扫雷** — 初级 / 中级 / 高级三档。第一下永远安全（布雷时避开你点的那格和它的八邻域），左键展开、右键循环 插旗 → 问号 → 空，数字格上中键或双击可以快开一片。
- **2048** — 标准 4×4 规则，滑动合并。支持撤销一步；合出 2048 会停下来问你继不继续。
- **纸牌接龙** — 经典 Klondike，七列收齐四门花色。可以一次翻 1 张或 3 张；牌局末尾剩牌全部翻开且牌堆清空时，会出现「自动完成」一键收尾。
- **俄罗斯方块** — 10×20，7-bag 随机、SRS 旋转与墙踢、幽灵落点、暂存位、锁定延迟。消行升级、四连消分数更高。
- **贪吃蛇** — 15×15，悠闲 / 正常 / 竞速三档。吃得越多蛇走得越快，触屏可以直接在棋盘上滑动转向。
- **工位模拟器** — 点「摸一下」或等工位自己产出摸鱼值，买齐八件工位装备抬高每秒产出，累计摸鱼值够数就升职（实习生 → 摸鱼合伙人），段位越高全局倍率越高。**从实习生做到摸鱼合伙人要按小时算**（八件装备再全部拉满还得几个小时），越往后每档越难。**关掉面板、切去玩别的期间按 40% 效率继续产出**，单次最多补 4 小时；回来先收到一张写清离岗多久、到手多少的结算纸条。
- **数独** — 三档难度（题面留 44 / 34 / 26 个已知数），点格子再填数字，实时标出同行同列同宫与相同数字，冲突会当场标红。卡住可以切「候选」看每个空格还能填什么。**切走再回来接着算**：题目与进度一起留着，被打断也不作废。
- **24 点** — 四张牌（1-9 或 A-K），点两张牌再点运算符合成一张，剩一张等于 24 就算赢。加减乘除走有理数精确计算，所以 `8 ÷ (3 − 8 ÷ 3)` 这类牌也算得对；合并出的牌下面写着算式。卡住可以「提示」替你先走一手，代价是这一局成绩加 30 秒。
- **局域网五子棋** — 15×15 标准规则，同一局域网里两台 PI-Desktop 各开一个面板就能下一盘。进游戏先看到棋盘：没房间时浮层告诉你怎么开局，下面只有「创建房间 / 刷新房间」和房间列表；昵称与「手动加入」在折叠的「联机设置」里，平时不占地方。规则只由房主算，两边看到的棋盘永远一致。断线判负、悔棋要对方点头、连成五子才结算，比分、手数和「下一局」都在棋盘上下。
- **局域网炸金花** — 2-5 人一张牌桌，每人三张牌比大小（豹子 > 顺金 > 金花 > 顺子 > 对子 > 散牌），A23 是最小的顺子，**235 三张不同花色能吃豹子**（同花的 235 只是金花）。闷牌（还没看牌）每次只出明牌的一半，看牌之后出全价；比牌要先看牌，而且照样要付一次跟注。房主开桌时选底注 / 单注封顶 / 起始筹码；筹码不够可以全下，结算按每人实际投入分层算边池。每一轮每个还在场的人都要按当前注额再下一次，直到只剩一人、封顶后全员跟到、或打到第 8 轮就开牌。牌桌和五子棋一样：房主离开就散桌，断线视为弃牌。

难度、翻牌张数、速度档位这些选择都会被记住，下次进来还是你上次的设定。

## 操作方式

| 游戏 | 键盘 | 鼠标 / 触屏 |
| --- | --- | --- |
| 扫雷 | `F` 给焦点格插旗 | 左键展开；右键循环 插旗 → 问号 → 空；数字格上中键或双击快开；触屏长按插旗 |
| 2048 | 方向键 / WASD | 棋盘上滑动；可撤销一步 |
| 纸牌接龙 | — | 点选再点目标，或直接拖拽；双击把牌自动送进回收堆 |
| 俄罗斯方块 | ← → 移动、↓ 软降、空格硬降、↑ 旋转、C/Shift 暂存、P/Esc 暂停 | 屏幕按钮 |
| 贪吃蛇 | 方向键 / WASD，空格暂停或重开 | 棋盘上滑动，或点下方方向键 |
| 工位模拟器 | 空格 / 回车摸一下 | 点「摸一下」赚钱；点行尾「买」升级装备；右上「×1 / ×10 / 拉满」切换一次买几级 |
| 数独 | 1-9 填数、`0` / `Backspace` 清空、方向键或 WASD 移动、`Ctrl+Z` 撤销、`H` 提示 | 点格子选中，再点下方数字键；工具条可切「候选」 |
| 24 点 | `1`-`4` 按位置选牌、`+` `-` `*` `/` 选运算符、`0` 清掉选中、`Ctrl+Z` 撤销、`H` 提示 | 依次点两张牌，再点运算符 |
| 局域网五子棋 | 方向键移动光标、回车落子 | 点棋盘落子，鼠标悬停预览落点 |
| 局域网炸金花 | — | 点「看牌 / 跟注 / 加注 / 比牌 / 弃牌」；加注金额填在输入框里，比牌先在旁边选人 |

面板顶部有「重开」，随时换一局；左上角的返回箭头回到游戏库。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 把游戏库和十款游戏挂在右侧工作面板的视图里 |

不申请 `fs.*`、`net.fetch`、剪贴板、通知或后台服务权限，也不注册 Agent 工具。两款联机玩法（五子棋 / 炸金花）走的是插件主进程里的 `node:net` / `node:dgram`，没有经过宿主的权限网关，但也只在开房或加入房间期间存在——不用就一直不占端口。插件没有任何文件读写入口，唯一用来持久化的是宿主提供的键值设置通道，只存下面那张表里的记录。

## 隐私

| 存什么 | 用在哪 |
| --- | --- |
| 每个游戏的最高分、胜负局数、累计局数 | 首页打卡行与各游戏内的「最高」 |
| 难度、翻牌张数、速度档位等选择 | 下次进来沿用 |
| 每天的游玩毫秒数 | 首页翻页时钟的「今日已摸」 |
| 工位模拟器的摸鱼值、装备等级、段位与上次离岗时间 | 离线结算，以及首页打卡行的段位与每秒产出 |
| 数独的题目、进度、难度与胜负局数 | 切走再回来接着算（题目与已填格一起落盘），以及首页打卡行的胜负与最快纪录 |
| 24 点的牌面、已走的步骤、牌型与胜负局数 | 切走再回来接着算（连同算式一起还原），以及首页打卡行的局数与最快纪录 |
| 五子棋的昵称、胜负平局数、上次加入的地址与端口 | 大厅昵称、首页打卡行的联机战绩，以及下次进来时预填「手动加入」 |
| 炸金花的昵称、胜负局数、净赢筹码、开房参数与上次加入的地址 | 牌桌昵称、首页打卡行的联机战绩，以及下次开桌时预填的底注 / 封顶 / 起始筹码 |

这些只写进插件自己的数据目录，不离开本机。首页只统计最近 31 天，超出的天数会在写入时自动丢弃。想清空记录，删掉插件数据目录里的设置文件即可。

## 界面

方向是办公室的「考勤表 + 打卡机」，不是圆角卡片墙：规则线承担分栏，圆角收紧，荧光笔标交互、印泥红标纪录和失败。

- 亮色叫「考勤表」：冷灰绿的再生纸底色、墨蓝正文、印泥绿强调色。暗色叫「夜班」：暖白正文配薄荷强调色。
- 跟随宿主的亮暗主题即时切换。
- 唯一会自己动的元素是那台翻页时钟；其余动效只在操作或状态变化时出现，静止时画面完全不动。
- 尊重系统的「减少动态效果」设置。

## 注意事项

- 纸牌接龙在很窄的面板里七列会偏挤：牌宽按容器宽度自适应（最小 34px），列内重叠间距同步压缩，不会出现横向滚动。
- 扫雷「高级」是 30 列。窄面板下棋盘内部会横向滚动（单元格不小于 16px），页面本身不会横向溢出。
- 首页战绩串较长时（例如接龙「99 胜 · 最快 12:34」），副标题会折成两行、行高变高——信息不丢，只是排版让位。
- 贪吃蛇与俄罗斯方块用 `canvas` 绘制，窗口缩放和换主题都会即时重绘。
- 没有音效，也没有联网排行榜——按设计如此。
- 工位模拟器离岗不足 1 分钟算连续摸鱼（全额入账），更久按 40% 计，单次上限 4 小时——它是唯一一个关掉面板还会继续跑的游戏。
- 数独的「候选」是当场算出来的视图，不落盘；棋盘放不下时会按容器宽度缩小单元格，窄面板下也不会横向溢出。
- 24 点用有理数而非浮点做四则运算，`24` 是精确判等，所以 `(3 − 8 ÷ 3)` 这类分数中间值不会被舍入误差带偏；提示走的那一手会计入成绩（加 30 秒罚时），撤销则连同罚时一起退回。
- 局域网五子棋要先有房间：房主点「创建房间」后，把棋盘上那串「本机地址:端口」发给对方（同在网段的人也可以直接从「局域网里找到的房间」点进）。房主离开这个游戏界面（或关掉面板）就散桌——它不做后台常驻房间。
- 五子棋的棋盘按面板宽度自适应（最短边决定边长，最小 160px）；面板很矮时，页面从棋盘往下滚，不会把按钮顶出可视区。
- 发现走 UDP 39731、房间走 TCP 39732，端口被占时自动换一个，界面上的「房间通道」显示的是真实端口。跨网段、VPN 和开了客户端隔离的访客 WiFi 通常互相看不见，这时改用「手动加入」填对方地址；对方也说连不上，先看 Windows 防火墙有没有放行。
- 局域网炸金花同样要先有房间：房主开桌时定底注 / 单注封顶 / 起始筹码，开好后把「本机地址:端口」发给同事，或让对方从房间列表点进来（列表里只显示炸金花的牌桌，并带出那桌的底注与封顶）。牌桌上最多 5 个人，局中加入的人下一局才发牌；房主离开这个游戏界面（或关掉面板）就散桌。
- 炸金花的「闷牌」是实打实的暗牌：没点「看牌」之前，连你自己手里那三张也不发到界面上（不是让前端藏起来），所以「闷牌只付一半」是拿信息换来的。看牌这件事对桌上是公开的，牌型只有本人（看牌后）和摊牌之后大家才看得到。
- 炸金花的底注与封顶开桌时定下，中途不能改；想换参数就散桌重开。比牌要付费，而且是「先看牌才能比」，比输了当场算弃牌。
